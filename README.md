# Datum — 逆算型ダイエットコーチ

目標体重と期日から「1日に必要な赤字」と「目標摂取量」を逆算し、毎日の記録で
「計画より何kg遅れている／進んでいるか」「このままだといつ届くか」「今日なにをすればいいか」を返すWebアプリです。

- **端末内保存**：記録はブラウザ内（IndexedDB）にだけ保存し、外部サーバーには送りません
- **PWA**：スマホのホーム画面に追加でき、オフラインでも動きます
- **CSV入出力**：Excel・Googleスプレッドシート・他アプリの書き出しを取り込めます
- **バックアップ**：記録・ゴール・設定・メモをJSONで書き出し、別の端末に移せます
- **話して記録**：「体重70.5キロ、1600キロカロリー、23時半に寝て6時に起きた」のように話すと、項目を読み取って入力します（保存前に確認画面）

## 画面

| 画面 | できること |
|---|---|
| ホーム | 計画との差、到達予測、今日やること、今日の残りカロリー、注意点、先週のふり返り |
| 記録する | 体重・食事（kcal / P / F / C）・運動・睡眠・メモの入力、過去の記録の編集・削除 |
| 食事・運動・体重・睡眠 | 項目ごとの推移と判定 |
| ふり返り | 週ごとの習慣、月ごとの平均体重（服薬期などを分けて比較） |
| ゴール | 目標体重・期日を設定 → 必要な赤字・目標摂取・計画線を逆算。無理なペースは警告し、無理のない期日を提案 |
| メモ | 検査値・外食の定番などを自由な表で保存 |
| 設定 | 維持カロリー（記録からの逆算つき）、安全下限、PFC、習慣の目標、判定から外す期間 |
| データ | CSV読み込み・書き出し、JSONバックアップ、全削除 |

## 計算方法

| 項目 | 式 |
|---|---|
| その日の収支 | 維持カロリー（運動を除く）＋ 運動 − 摂取（＋なら赤字） |
| 必要な1日の赤字 | （現在の体重 − 目標体重）× 7,000 ÷ 期日までの日数 |
| 目標摂取 | 維持カロリー ＋ 平均運動 − 必要な赤字。ただし設定した安全下限より下げない（足りない分は運動の上乗せとして提示） |
| 計画線 | 開始日の体重から期日の目標体重まで直線 |
| 到達予測 | 残りkg × 7,000 ÷ 直近14日の平均赤字 |
| 体重の判定 | 7日移動平均（記録が3日以上ある場合） |
| 維持カロリーの逆算 | 平均摂取 − 平均運動 − 体重変化（期間の最初と最後の7日平均の差）× 7,000 ÷ 日数（摂取の記録14日以上） |
| 基礎代謝 | 国立健康・栄養研究所の式（Ganpule式）：(0.0481×体重 + 0.0234×身長 − 0.0138×年齢 − 定数) × 1000 ÷ 4.186、定数は男性0.4235・女性0.9708 |
| 運動の消費 | (メッツ − 1) × 体重 × 時間 × 1.05（安静時ぶんを引いた正味） |

ペースの目安（週に体重の0.7%で注意、1.0%で警告）は**このアプリの既定値で、医学的な基準ではありません**。
持病・服薬がある場合は主治医に相談してください。

### 出典

- 国立健康・栄養研究所の基礎代謝推定式：Ganpule AA, et al. *Eur J Clin Nutr* 2007;61:1256–1261. 解説：[長寿科学振興財団 健康長寿ネット](https://www.tyojyu.or.jp/net/kenkou-tyoju/tairyoku-kiki/energy-sokutei.html)
- PFCの目標量（たんぱく質13〜20%E、脂質20〜30%E、炭水化物50〜65%E）：[厚生労働省「日本人の食事摂取基準」](https://www.mhlw.go.jp/stf/newpage_44138.html)
- メッツ値：[国立健康・栄養研究所「改訂版 身体活動のメッツ（METs）表」](https://www.nibiohn.go.jp/eiken/programs/2011mets.pdf)
- 運動量の目安：[厚生労働省「健康づくりのための身体活動・運動ガイド2023」](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/kenkou_iryou/kenkou/undou/index.html)

## 話して記録

ホームの「話して記録する」、または「記録する」画面から使えます。

- 項目名か単位と一緒に話します：「体重〇〇キロ」「〇〇キロカロリー」「たんぱく質／脂質／炭水化物〇〇グラム」「運動は〇〇で〇〇キロカロリー」「〇時に寝て〇時に起きた」「夜中に〇回起きた」「メモ、…」
- 「昨日の…」「おとといの…」で日付を変えられます。言わなかった項目は変更しません
- 漢数字（「七十点五」「千六百」）でも読めます
- 音声を文字にするのはブラウザの Web Speech API です（Chrome は Google、Safari は Apple のサービスで変換）。非対応のブラウザでは、文章欄にキーボードの音声入力で話しても同じように読み取ります
- 読み取りのルールは `src/lib/voice.ts`（テストは `voice.test.ts`）

## CSVの形式

1行目は見出し、**「日付」列は必須**。ほかの列は任意で、順番も自由です。

```
日付,体重kg,摂取kcal,たんぱく質g,脂質g,炭水化物g,運動kcal,運動内容,就寝,起床,中途覚醒回数,メモ
2026-11-01,70.5,1600,110,42,190,258,ブートキャンプ30分,23:00,6:00,1,昼は和定食
```

- 英語の見出し（`date, weight, kcal, protein, fat, carb, exercise, bed, wake, note` など）や、「体重」「摂取カロリー」などの言い換えも読めます
- 日付は `2026-11-01` / `2026/11/1` / `2026年11月1日`
- 数値の桁区切り（`1,600`）、全角数字、単位つき（`70.5kg`）も読めます
- UTF-8 と Shift_JIS（Excelの既定）のどちらでも読めます
- スプレッドシートからコピーしたタブ区切りをそのまま貼り付けられます
- 同じ日付の記録は「CSVで上書き」か「空欄だけ埋める」を選べます

```bash
npm install
```

```bash
npm run dev
```

```bash

```


構成：React 18 + TypeScript + Vite、IndexedDB（idb）、vite-plugin-pwa、テストは Vitest。

```
src/
  lib/calc.ts    計算（収支・移動平均・基礎代謝・ゴールの逆算・維持カロリーの逆算）
  lib/coach.ts   伴走（今日やること・アドバイス・到達予測・週/月のふり返り）
  lib/csv.ts     CSVの読み込み・書き出し・取り込みのマージ
  lib/db.ts      IndexedDB とバックアップ形式
  lib/voice.ts   話した文章から記録の項目を読み取る
  pages/         画面
```

## 公開する（GitHub Pages）

`main` に push すると、Actions がビルドして `gh-pages` ブランチに公開します。
`https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます。

- 公開されない場合は、リポジトリの `Settings → Pages` で「Deploy from a branch」・ブランチ `gh-pages`・フォルダ `/ (root)` になっているか確認してください
- 公開されるのはアプリのプログラムだけです。記録は各端末のブラウザ内にあり、公開URLから他人に見えることはありません

## データの扱い

- 記録・設定・メモはブラウザの IndexedDB に保存します。外部への送信はありません
- ブラウザのサイトデータを消すと記録も消えます。「データ」画面から定期的にバックアップを保存してください
- **個人の記録やバックアップファイルはリポジトリに入れないでください**（`data/` と `*-backup*.json` は `.gitignore` 済み）
